# Phase-P0 tool-path experiment, 2026-09-14

Question: Can the observable pin/timer circuit pass the generated-RTL path and
begin the competition's intended CMOS5L physical flow?

Update, 2026-09-15: the competition page specifies `6x4` as the current maximum;
`8x4` is only a possible future expansion. The pinned CMOS5L support-tools
revision contains the required `6x4` tile entry and DEF, so the earlier floorplan
blocker was based on an incorrect reading of the current requirement.

Conclusion: P0.1–P0.3 are reproducible locally. The physical flow selections are
pinned, and the current `6x4` floorplan is present and validated. P0.4 and P0.5
remain open until mapped CMOS5L synthesis and the full physical run complete.

Limitations: no installed local PDK, LibreLane, container runtime, OpenROAD, or
physical verification tools. Placement, routing, timing, physical checks,
precheck, and gate-level simulation have not run.
