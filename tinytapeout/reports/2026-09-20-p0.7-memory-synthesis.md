Date: 2026-09-20. Consumer base revision: `fbe0a98`. Evidence archive:
[`flow_results/20260920-071538-a538212c`](../../flow_results/20260920-071538-a538212c/README.md).

## Implemented

`bin/asic_bundle.ml` retains the existing observable declaration and adds a
selectable `memory` declaration. It connects P3.1a's plain-Hardcaml
`Protocol_core` port to one context-registered `Single_port_ram` named `program`.
The project policy is explicitly `Flops`; simulation elaboration uses the
library behavioral model and implementation elaboration uses generated flop
RTL with a registered read output and no initialization.

The consumer shape is the adopted P3.1a/P1.5 default: 256 sixteen-bit words
(4,096 storage bits), one whole-word 1RW port, and one-cycle reads. The TT
fixture stages complete 16-bit words over two cycles, exposes all eight address
bits, and maps a zero load-start length to 256 so synthesis cannot discard an
unreachable portion of the declared resource. It is a diagnostic adapter, not
the P3 loader or host protocol.

Validity, sequential load coverage, ordered full-word verification, image bounds,
halted/engine-idle access gating, response ownership, and reset/disable behavior
remain in `Protocol_core`. Reset invalidates consumer metadata and never clears
RAM. Rejected accesses issue no RAM operation, and post-write, unwritten, stale,
or held outputs are consumed only when independently tracked response validity
is asserted.

### ABC diagnostics

The raw log's driving-cell message is a real constraint-translation defect, not
a missing Liberty cell. The PDK and Liberty define cell `sg13cmos5l_buf_4` with
output pin `X`. LibreLane configuration correctly uses its documented
`cell/port` spelling, but pinned LibreLane `3.1.0.dev3` writes that combined
token verbatim to ABC. ABC's `read_constr` grammar accepts only a cell-name token
and performs an exact cell lookup, so it searched for nonexistent cell
`sg13cmos5l_buf_4/X`. OpenSTA's SDC grammar is different: the emitted
`constraints/top.sdc` correctly names `-lib_cell sg13cmos5l_buf_4 -pin X`.

The requested PI driving-cell slew/delay was therefore absent from ABC's final
`stime -p` estimate; the 6 fF output load was applied. In this exact `AREA 0`
run, with `SYNTH_ABC_BUFFERING=false`, `SYNTH_SIZING=false`, and
`SYNTH_ABC_DFF=false`, the lookup occurs after mapping and cannot affect mapped
cell choices or area. The 10,013.10 ps ABC path print is not valid timing
evidence. The narrow correction belongs in LibreLane's ABC-constraint renderer,
which must split its documented `{cell}/{port}` value before writing ABC input.
Changing the library-owned emitted config to a bare cell would violate the
LibreLane/OpenSTA contract, and patching the installed environment would be
untracked, so neither workaround was applied.

The nearby `Error: The network is combinational.` is `scleanup` reporting that
there are no latches in the combinational network Yosys passed to ABC. The
strategy's `retime` operations are also no-ops for that reason. ABC continues to
map and write its output; this is benign for the selected script and is distinct
from the driving-cell lookup failure. Zero structured synthesis-check errors do
not suppress or disprove either raw-log diagnostic.
